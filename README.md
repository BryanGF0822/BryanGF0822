## 👋 About me

I'm an **iOS Developer at [Globant](https://www.globant.com/)** building production apps with **Swift** and **SwiftUI** for the banking sector. I care about clean, testable code and about understanding *why* an architecture works — not just how to wire it up.

Before iOS I worked on **C#/.NET backends** and **Python data engineering**, so I'm comfortable on both sides of an API.

- 🏦 Working on mobile banking apps used by millions of customers
- 🏗 Building with **MVVM + Clean Architecture** (clear layers, one-way data flow)
- 🧪 Leveling up in **unit testing**, **Swift Concurrency** and **Combine**
- 🚀 Learning the full release cycle: CI/CD, TestFlight and **App Store** deployment
- 🇨🇴 Based in **Cali, Colombia** · Español (native) · English
